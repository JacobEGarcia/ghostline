GHOSTLINE

A fully local, uncensored chat uplink. Everything runs on your machine. Nothing leaves it.

Built for Qwen3.5-9B Abliterated on Ollama. To load the model:

ollama pull hf.co/lukey03/Qwen3.5-9B-abliterated-GGUF:Q4_K_M

Pick the model in the sidebar and talk. Personas tune the system prompt; RAW sends nothing.

Opened as a file, this works with Ollama's default origins. Hosted on the web, set OLLAMA_ORIGINS to allow the site (see Setup).

READY

SETUP // UPLINK

1. Install Ollama (once): winget install Ollama.Ollama or ollama.com/download

2. Pull the model (5.2 GB, once):

ollama pull hf.co/lukey03/Qwen3.5-9B-abliterated-GGUF:Q4_K_M

3a. Using GHOSTLINE as a file (double-clicked from disk): nothing else needed. Ollama trusts file:// origins by default.

3b. Using the hosted page: allow its origin once, then restart Ollama:

setx OLLAMA_ORIGINS "https://jacobegarcia.github.io"

Mac/Linux: launchctl setenv OLLAMA_ORIGINS ... / export OLLAMA_ORIGINS=...

LM Studio: start the local server (Developer tab → Start Server, port 1234), then switch Engine in the sidebar.
